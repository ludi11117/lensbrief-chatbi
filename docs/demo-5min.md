# LensBrief 五分钟演示

准备工作台和 [sample-sales.csv](sample-sales.csv)。默认地址为 `http://localhost:8080`，保持 Mock 模式。登录页可填入演示账号。

| 时间 | 操作 | 面试官可以核对 |
| --- | --- | --- |
| 0:00–0:35 | 选「华东分析师」登录。在报告中心选择草稿状态，再重置。 | 报告按范围展示，可按关键字、状态和页码查询。分析师侧栏隐藏权限管理。 |
| 0:35–1:35 | 点「新建报告」，输入「2026年10月按渠道看销售额」。解析后核对条件，再运行查询并生成草稿。把标题改为「十月渠道复盘」，上传 CSV 并保存。 | 指标、维度和日期先自动填入表单。执行后预览显示图表和口径。复制报告详情 URL。 |
| 1:35–2:05 | 点「发布报告」并确认。在 v1 下提交「请核对渠道归类」。 | 当前发布为 v1。反馈绑定 v1，后来发布的版本拥有独立讨论。 |
| 2:05–2:55 | 编辑标题和正文，保存，再发布。用「对比版本」比较 v1 与 v2。 | v2 是当前版本。对话框显示旧值、新值及正文每一行的增删。 |
| 2:55–3:35 | 关闭对比，在 v1 行点「回滚」。 | 当前变成 v3，标记恢复自 v1。v2 仍可预览。 |
| 3:35–4:05 | 退出，登录「海外分析师」，粘贴报告 URL。 | 页面和浏览器 Network 中的详情请求均显示 403。 |
| 4:05–4:35 | 切回「华东分析师」，打开报告和 CSV 附件。 | 浏览器显示表格，可以下载原文件。 |
| 4:35–5:00 | 点「查询记录」，按用户 ID 1、今天的 UTC 日期筛选，打开刚才的销售额查询。 | 日志显示执行状态、范围、返回行数和结果。管理员可在权限管理页勾选「只看越权记录」，核对海外账号、报告编号和被拒绝的 `report.read`。 |

追问事务时，在 `backend/tests/test_api.py` 打开 `test_publish_failure_rolls_back_status_version_attachments_and_audit`。用例在写入审计行后注入异常，再用独立数据库会话验证报告、版本、附件关联和审计一起撤销。

追问性能时，可打开查询计划中的 `owner_first` 和 `department_first`。同一批一万条合成报告，分析师可见 3,334 条，主管可见 6,667 条。两次查询分别使用报告所有者索引和部门索引。计时原始记录可以重算 P50 和 P95。 [原始样本](benchmarks/samples.csv) · [查询计划](benchmarks/summary.json)

可把开始时的「新建报告」换成「分析上下文」里的「新建报告」。演示前创建「十月渠道复盘」上下文并选择「渠道销售复盘」知识包。运行销售额查询后可展开「知识包 v1」查看口径，也可追问「改按产品」，核对沿用的指标和日期。回到上下文可查看两次执行记录。

README 的截图由浏览器测试生成。用演示数据库启动工作台，在 `frontend` 目录运行以下命令：

```sh
LENSBRIEF_SCREENSHOT_DIR="$PWD/../docs/media" npm run test:browser
```

PowerShell 可先执行 `$env:LENSBRIEF_SCREENSHOT_DIR = Join-Path (Resolve-Path ..) 'docs/media'`，再运行 `npm run test:browser`。
